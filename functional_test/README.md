# Functional Test Package

The 8.0.2 lab uses catalog-driven validation. To run a single live case and
correlate its Traffic Log entry, use `python3 -m functional_test
catalog-baseline --help`. To evaluate saved observations, use `python3 -m
functional_test evaluate-catalog --help`. The student chatbot also provides a
Tests tab.

See [Functional Validation](../docs/functional-validation.md) for credentials,
commands and limitations. The earlier scenario installer and legacy baseline
are available on `archive/8.0.1` and the `faig_8.0.2_gui_experiment` tag.
