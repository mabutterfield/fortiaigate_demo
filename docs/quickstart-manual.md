# Manual Deployment Reference Has Moved

Manual Terraform and playbook-by-playbook installation is no longer presented
as a second quickstart.

Use:

- [Deployment Quickstart](quickstart.md) for the supported AWS and local
  installation journey;
- [Operations](operations.md) for component reruns, status, updates,
  validation, and teardown;
- [Troubleshooting](troubleshooting.md) to choose a recovery command by
  symptom;
- [Terraform](terraform.md) for module ownership and outputs;
- [Container Repository Management](container-repository-management.md) for
  ECR, local registries, and image publication; and
- [Command And Inventory Reference](reference/command-inventory.md) for
  repository-root command and inventory conventions.
