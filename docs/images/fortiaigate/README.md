# FortiAIGate Documentation Images

Reviewed screenshots referenced by the FortiAIGate initial and scenario GUI
guides live in this directory. Filenames and completion state are recorded in
the parent-workspace capture inventory.

Before committing an image, remove or obscure credentials, API keys, license
identifiers, serial numbers, private addresses, customer data, browser account
details, and unrelated UI objects. Use synthetic placeholder values wherever
the FortiAIGate form accepts them.
