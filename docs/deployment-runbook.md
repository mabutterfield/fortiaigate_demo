# Deployment Runbook Has Moved

The former end-to-end manual runbook duplicated the automated deployment and
is no longer a separate installation lane.

Use:

- [Deployment Quickstart](quickstart.md) for a new AWS or local deployment;
- [Operations](operations.md) for repeat runs, component redeploys, status,
  updates, functional validation, and teardown; and
- [Troubleshooting](troubleshooting.md) for symptom-driven recovery.

Detailed component authorities remain linked from the
[Documentation Map](README.md). This compatibility page preserves the
established URL for bookmarks and external links.
