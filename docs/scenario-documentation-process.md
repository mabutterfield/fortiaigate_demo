# Scenario Documentation Process Has Moved

[Scenario Authoring](scenario-authoring.md) now owns package structure,
instructions, tools, actions, prompts, validation cases, functional curl
templates, transcript replays, README structure, screenshots, evidence,
promotion, and deployment boundaries.

Use [Scenario Management](scenario-management.md) for installation, local
tuning, update/backup, validation, and removal. This compatibility page
preserves the former documentation path without maintaining a second process.
