# Automated Quickstart Documentation Has Moved

[Deployment Quickstart](quickstart.md) is the single supported first-run guide
for both AWS and local Ubuntu deployments.

The deployment command remains:

```bash
# AWS
python3 scripts/automated_quickstart.py

# Local Ubuntu
python3 scripts/automated_quickstart.py --local
```

Before running it, complete [First-Run Preparation](first-run-preparation.md)
and [Deployment Options](deployment-options.md). For repeat runs, component
reruns, updates, validation, and teardown, use [Operations](operations.md).

This compatibility page preserves the established URL without maintaining a
second copy of the deployment journey.
